# Data

Place here (file names as used by the notebooks):

* `jateng_panel_2020_2024_full.csv` — columns `Kabupaten_Kota, Tahun, PDRB, Kemiskinan, Sanitasi, KontribusiIndustri, PertumbuhanIndustri, JumlahIndustri, TPAK, TPT, IPM`; 35 regencies/cities x 5 years. Variables used: Kemiskinan (poverty rate, %), PertumbuhanIndustri (manufacturing growth, %), log(PDRB) (log GRDP), TPT (open unemployment rate, %), Sanitasi (access to improved sanitation, %).
* `profile_presample_2019` — 2019 GRDP at constant 2010 prices, open unemployment rate, labour-force participation rate (Sakernas August 2019).
* Boundary file of Jawa Tengah regencies (BIG, EPSG:4326) used for queen contiguity and centroid distances.

Source: BPS-Statistics of Jawa Tengah Province (public tables); Badan Informasi Geospasial. If redistribution of the raw files is not permitted, list the BPS table identifiers and download dates here instead.
